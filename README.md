## Como avalio uma automação

Uma entrega não está pronta apenas porque executou uma vez. Procuro deixar claro o contrato de entrada e saída, idempotência e deduplicação quando aplicáveis, caminhos de erro, histórico/auditoria, limites dos provedores e a evidência disponível. Nos projetos públicos, segredos, dados de clientes e integrações internas são removidos; limitações que dependem de acesso externo também são documentadas.
