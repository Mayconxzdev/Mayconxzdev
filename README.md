## Como apresento evidências

Um fluxo não é considerado pronto apenas porque executou uma vez. Nos projetos, procuro separar claramente:

- **produção, uso interno, piloto, sandbox e demonstração**;
- números do sistema completo e números de um workflow específico;
- funcionalidade implementada, testada, executada e validada por usuário;
- código público, arquitetura sanitizada e componentes privados;
- resultado observado, limitação conhecida e próximo gate de evolução.

Credenciais, dados pessoais, fornecedores, preços, documentos empresariais e caminhos internos não são publicados.
