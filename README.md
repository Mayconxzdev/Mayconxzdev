## Resultados em uso

- **10 mil+ execuções de workflows em produção** no ambiente n8n que administro; o volume é do ambiente, não de um único fluxo.
- Propostas simples passaram de **2–4 minutos para menos de 30 segundos**, com uso diário por 4 profissionais.
- Produção Operacional implantada em **10+ computadores e uma TV**, apoiando **20+ profissionais em 9 setores produtivos**.
- **Belarc Inventory em uso interno**, co-desenvolvido com agente Windows em Rust, servidor Axum/SQLite e coleta PowerShell/CIM.

## Como trabalho

Entendo o fluxo e suas exceções, escolho o nível adequado de automação, integro APIs ou sistemas internos, testo falhas e duplicidades, e preparo implantação, treinamento e suporte. Em etapas com efeitos externos ou conteúdo gerado por IA, mantenho aprovação humana e limites explícitos.

**Núcleo:** n8n · Power Automate · Python · APIs REST/JSON · webhooks · SQL.

**Provas adjacentes:** Power Automate Cloud/Desktop, Prompt Engineering, FastAPI, PostgreSQL, Redis, Power BI/Power Query e sistemas Windows em Rust/PowerShell, sempre apresentados no contexto do projeto correspondente.

Minha experiência com MCP é documentada pelas **Microsoft Applied Skills — MCP Tools with Agents**; não apresento servidor ou cliente MCP próprio como projeto comprovado. Em IA, o case Postagem Redes está rotulado como validado em teste. Não alego agentes ou RAG em produção.
