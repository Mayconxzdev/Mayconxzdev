## My approach to AI-led delivery

- **Before implementation:** requirements, architecture, data contracts, versioned specifications and acceptance criteria.
- **During implementation:** context engineering, task planning and supervised AI agents.
- **Before delivery:** diff review, business logic and security checks, automated tests, documentation and deployment.

Generating code with AI is not the same as validating software. The goal is reliable, maintainable outcomes.
