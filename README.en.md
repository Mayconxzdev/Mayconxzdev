## How I work

I learn the rules and exceptions from the people who use a process, look for the simplest useful solution and stay involved through rollout. When a task keeps recurring, I look for a way to turn it into an automation or tool the team can use and maintain.

Related experience includes user and internal systems support, Power BI and Power Query, data integration, earlier hands-on AWS projects and Windows application development. The portfolio explains what I built and the context for each project.
